# Surgical Revenue Compass

Vamos criar uma healtech no nicho de revenue cycle manangment. Neste MVP, vamos focar na cadeia de uma cirurgia, focado na otimização. Dentro do escopo de auditoria, foco na captura de cobranças e integridade da receita. Isso basicamente é feito com cruzamento de dados de prontuarios. Tudo utilizado deve ser devidamente conferido na conta do paciente. Na otimização do bloco, foco em redução de cancelamento cirúrgicos e aumento da quantidade de cirurgias por dia.
